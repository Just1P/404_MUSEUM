# 404 MUSEUM

Projet React + TypeScript + Vite.

## Prérequis

- [Node.js](https://nodejs.org/) (≥ 18)
- [pnpm](https://pnpm.io/) (le projet utilise un `pnpm-lock.yaml`)

## Installation

```bash
pnpm install
```

## Lancer le projet

```bash
pnpm dev
```

Le site est ensuite accessible sur l'URL affichée dans le terminal (par défaut [http://localhost:5173](http://localhost:5173)).

## Autres commandes

```bash
pnpm build      # build de production (type-check + vite build)
pnpm preview    # prévisualiser le build de production
pnpm lint       # lancer ESLint
pnpm solve <n>  # résoudre le niveau n du Layout 404B (script CLI)
```
